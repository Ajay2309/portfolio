01 PROJECT · CYBERSECURITY INTERNSHIP

Image Steganography

A Python-based tool that securely conceals secret text messages inside digital images using image processing techniques, and extracts them again when required. Supports PNG, JPEG and BMP, and ships with a command-line interface for encoding and decoding.

  • Message encoding and decoding to hide and retrieve confidential information.
  • Multi-format support — PNG, JPEG and BMP — for flexible hiding and extraction.
  • CLI to simplify user interaction and run encode / decode operations.
  • Separated modules for image processing, message hiding and message extraction.
  • Python
  • Image Processing
  • Steganography
  • CLI
